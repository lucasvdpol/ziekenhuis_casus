Ziekenhuis Informatie & Rapportage Systeem

Dit project was gericht op het optimaliseren van de operationele bedrijfsvoering van een ziekenhuis. Het ziekenhuis kampte met een gebrek aan inzicht in de bezettingsgraad van bedden, de inzet van personeel en patiëntenstromen per afdeling. Wij kregen de opdracht om een nieuw database-ontwerp te realiseren, de data te transformeren en deze inzichtelijk te maken via een BI-dashboard.

De Workflow

Het project bestond uit drie hoofdfasen:
-Database Engineering: Analyse van de bestaande (complexe) database en het ontwerpen van een genormaliseerd database-schema dat schaalbaar en efficiënt is voor rapportage.
-Data Engineering: Migratie en opschoning van de data, inclusief het automatiseren van datatransfer. Als onderdeel van de technische verkenning heb ik een datascraper (Python/BeautifulSoup) gebouwd om relevante richtlijnen en protocollen (zoals BRMO-richtlijnen van het RIVM) te extraheren voor integratie in het systeem.
-Business Intelligence (Power BI): Ontwikkeling van een interactief dashboard. Dit dashboard bood de directie van het ziekenhuis real-time inzicht in de capaciteitsplanning en personeelsbezetting, wat direct bijdroeg aan betere besluitvorming.

Technische Stack
-Database: SQL (Database modellering & query optimalisatie).
-Data Verzameling: Python (Requests & BeautifulSoup voor web scraping).
-Business Intelligence: Power BI (Data modeling, DAX-formules & visualisatie).

Bijdrage
-Consultancy: Vertalen van de behoeften van de ziekenhuisdirectie naar technische eisen.
-Data Modelling: Ontwerp van het relationele datamodel.
-Dashboarding: Ontwikkelen van interactieve rapportages die complexe data begrijpelijk maakten voor niet-technische stakeholders.
